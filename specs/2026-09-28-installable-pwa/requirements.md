# Feature 13: Installable PWA — Requirements

Roadmap row 13. Branch `spec/2026-09-28-installable-pwa`.
Design authority: [Requirement 1 of the web technical design](../tech-design-web.md#requirement-1-a-calculator-application-for-web-and-mobile) (Installability: HTTPS; manifest linked from every page with name and short name, start URL, icons at 192 and 512 pixels, standalone display; a service worker is not required for installability).

## Goal

Make the calculator installable. A web app manifest describes the app so supporting browsers offer installation and the installed app opens in its own window without browser chrome. Icons are generated by a small script in the repository so the project stays free of binary assets that cannot be reviewed.

## Must do

### Manifest
- R1. A manifest file in the source folder declares a name, a short name, a start URL of the app root, a display mode of standalone, a background colour and a theme colour taken from the light theme tokens, and an icons list.
- R2. The icons list contains PNG icons at exactly 192 by 192 and 512 by 512 pixels with correct sizes and type members, and does not set the prefer-related-applications flag.
- R3. The page links the manifest with a link element and declares a theme colour meta tag matching the manifest.

### Icons
- R4. A script under the tools folder generates the two PNG icons with no dependencies beyond Node's built-in modules, drawing a simple equals-sign mark on a solid background, and writing deterministic bytes so regenerating produces identical files.
- R5. The generated icons are committed so a fresh clone serves them without running the script.

### Serving
- R6. The local static server serves the manifest with the manifest media type and the icons as PNG.

### Tests
- R7. Automated tests parse the manifest, check the required members, verify each icon file exists and its PNG header reports the declared size, verify the page links the manifest and theme colour, verify the server's media type table, and regenerate the icons in memory to confirm they match the committed bytes. A manual scenario covers the browser's install prompt over HTTPS.

## Explicitly not included

- No service worker or offline caching (row 14).
- No app-store packaging (not on the roadmap).
- No localisation of the manifest (not on the roadmap).
