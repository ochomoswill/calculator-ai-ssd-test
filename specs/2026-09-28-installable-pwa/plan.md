# Feature 13: Installable PWA — Plan

Plain HTML and JSON with one zero-dependency Node script; tests run with Node's built-in test runner. No CSS, engine, formatter or dependency changes.

## Tooling
| File | Purpose |
|---|---|
| `tools/make-icons.js` | New. Encodes a PNG (built-in zlib for the image data, a small CRC routine) of a given size with the equals-sign mark, exports the encoder for tests, and writes the two icons when run directly. |
| `tools/serve.js` | Unchanged. Already serves `.webmanifest` and `.png` with the right media types. |
| `package.json` | Changed. Adds an `icons` script that runs the generator. |

## HTML
| File | Purpose |
|---|---|
| `src/index.html` | Changed. Adds the manifest link and the theme-colour meta tag. |
| `src/manifest.webmanifest` | New. The manifest described in requirements R1 and R2. |
| `src/icons/icon-192.png`, `src/icons/icon-512.png` | New. Generated by the tool and committed. |

## CSS
| File | Purpose |
|---|---|
| none | Unchanged. |

## JavaScript
| File | Purpose |
|---|---|
| none | No application modules change. |

## Tests
| File | Purpose |
|---|---|
| `test/pwa.test.js` | New. Tests for acceptance scenarios A1 to A6. |

## Out of scope for this plan
No service worker, no store packaging, no manifest localisation.
